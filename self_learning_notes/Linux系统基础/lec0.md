# 命令
回显 echo
创建文件夹 mkdir
\用于命令换行或者转义
pwd获取当前工作目录

环境变量$PATH定义了Linux系统中的路径
第一次执行命令时会从左到右沿着$PATH查找相应的命令
找不到时报错
之后会将这个命令存到一个哈希值中，执行时直接读取

显示命令 A 所在的位置的命令：
which A

输入的命令如果不是精确的一长串路径，则会由shell来解释

在Linux中所有东西都被视为file，由目录呈现，有一个统一的根目录

# 目录含义解析
bin 可执行文件
boot Linux内核 启动文件
dev  设备和接口文件
etc 重要 存放配置文件（用户信息 密码信息……）
home 普通用户的主目录
lib64 库函数
opt 第三方软件
proc 虚拟文件系统 （系统内核 进程状态……）
usr 用户信息
/sbin == /usr/sbin
var 变量（日志文件）
tmp 临时文件

重定向和管道

输入流默认键盘 输出流默认屏幕

![[CS106L/picture/image-5.png|321x189]]

`>`|输出重定向|清空覆盖|写入新内容|
`<`|输入重定向|不影响|把文件当作输入数据源|
`>>`|输出重定向（追加）|保留原内容，末尾追加|添加新内容而不覆盖|

管道操作符 |   链接一个程序输出与另一个程序输入
作用：实现多个命令之间的连接
eg： ls -l /usr/bin | less 显示bim中的目录，并且传递给less，实现控制

管道符由shell进行解析

rm命令不接受输入，只接受键盘参数
xargs命令：把输入转换为参数，传递给后一个命令
ls | xargs rm  删除所有文件夹中的文件

只有sudo组中的用户可以执行sudo命令
转换身份为超级用户：sudo -i 模拟一个超级用户重新登陆
sudo su 提升身份
恢复身份 exit

tee命令 把输入内容同时输出给屏幕和后方文件中

sudo命令和一些特殊字符还有特殊作用

软件包更新很重要
