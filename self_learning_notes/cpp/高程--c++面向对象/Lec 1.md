cpp对顺序比较严格，在调用前必须先见到定义

初始化顺序只跟成员变量的定义顺序有关，与初始化列表无关，因为这现在了他们在物理内存中的布局

```cpp
class A
{
int a = 1;//本地初始化
const int b;
bool c;
public:
A(const int m):c(false)//成员初始化列表
{b = m;}//构造函数

~A();//析构函数--扔垃圾
//note:如果在类内部额外申请资源，那么必须要写析构函数，且必须写清楚定义
}
```

执行的先后顺序依次向下

拷贝构造函数：
```
class A{
A();//默认
A(const A &a);//拷贝构造
}
```

调用拷贝的情况：
1.创建对象显示指出
2.值传递对象函数参数，构造形参
3.对象作为函数返回值

默认的拷贝函数实现：
1.对于对象类型，递归调用
2.对于基本类型，直接复制
