## 🧭 Java 全栈开发学习路径（整合 CS61B）

### **阶段一：Java 基础（Java SE）**

**目标**：​掌握 Java 语言的基本语法、面向对象编程思想、常用 API 和开发工具。​

**学习内容**：

- Java 基本语法、数据类型、流程控制
    
- 面向对象编程（封装、继承、多态）
    
- 异常处理、集合框架、泛型
    
- 多线程与并发编程
    
- I/O 流操作
    
- Java 虚拟机（JVM）基础​
    

**推荐资源**：

- 尚硅谷 Java 入门教程（Bilibili）
    
- 《Java 核心技术 卷 I》​
    

---

### **阶段二：CS61B - 数据结构与算法**

**目标**：​深入理解数据结构与算法，提升编程能力和软件工程实践水平。​

**课程简介**：

- 课程名称：CS61B: Data Structures
    
- 授课语言：Java
    
- 课程主页：[CS61B Spring 2025](https://sp25.datastructur.es/)​
    

**学习内容**：

- 线性表、队列、栈、链表、树、图等基本数据结构
    
- 排序与查找算法
    
- 泛型、接口、继承与多态等面向对象编程概念
    
- 时间复杂度分析与算法优化
    
- 大型项目的设计与实现，强调软件工程实践​
    

**推荐资源**：
