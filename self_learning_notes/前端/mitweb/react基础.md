# 关键特性
## 抽象和通用化组件，属性（props）
属性（差异内容）-注入-> 框架（复用内容）->渲染出ui界面
属性是由父组件传递给子组件的，子组件只能使用属性，但不能修改属性值
**如何修改数据？** 如果子组件需要“修改”数据，它不能直接修改 props。正确的做法是：

1. 父组件将一个**修改数据的方法**作为 prop 传递给子组件。

2. 子组件在需要修改数据时，**调用**这个父组件传递下来的方法。
    
3. 这个方法在父组件中执行，然后父组件更新自身的状态（state），状态的更新会触发组件重新渲染，并将新的数据作为 props 传递给子组件。

## 状态机制（State）
组件维护信息，可变
例如：将待传递的评论放在帖子组件的state中，由此传递给评论组件的props
大概就是较大一级的组件的state存放低一级组件的props，满足由上到下的流程控制
