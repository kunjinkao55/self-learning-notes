#群的定义
代数系统：封闭性
半群：满足结合律的给定代数系统
幺半群：半群，并且存在单位元
群：幺半群的基础上存在逆元

群的等价描述：G是非空集合,$*是G上一个二元运算，对于 ∀x∈G 都有逆元x^{−1}存在， 则称<G,*>是一个群$

#群的性质
一、乘法性质
$1. (a^{-1})^{-1} = a$
2.$(ab)^{-1} = b^{-1}a^{-1}$
3.ab = ac   -> b = c
4.ba = ca -> b = c
5.ax = b , ya = b 对x，y有唯一解
5的推论：有限群的运算表中每行（或者列）均为群中所有元素的一种排列

二、阶性质
$a^0 = e（单位元）$ 
$a^{n+1} = a · a^n$
$a^{-k} = (a^{-1})^k$

元素的阶：周期
G是群 a∈G a的阶为：
|a| = min{k ∈ $Z^+ | a^k = e$}
如果k不存在，称a为无限阶元

元素性质
有限群不存在无限阶元
群中元素及其逆元有相同的阶
有限群中阶大于2的元有偶数个
偶数群中阶为2的元素有奇数个
（偶数群：有偶数个元素的群）

#子群

定义：$<G,\cdot> 是群，H是G非空子集，若<H,\cdot>也是群，则H是G的子群，记作 H<=G$



定理一：判定定理：G是群，H是G的子集，H是G的子群当且仅当：
$\forall a,b \in H,ab \in H, 并且 \forall a \in H,a^{-1} \in H$
（子集 满足封闭性，逆元）
或者写为：

定理二：判定定理：G是群，H是G的子集，H是G的子群当且仅当：
$\forall a,b \in H,ab^{-1} \in H$ 
必要性显然，下证明是群的充分性：
1.单位元：令 a = b，bb$^{-1} \in H$,则有单位元
2.逆元： 因为已经有单位元，所以令a = e，然后就有逆元
3.封闭性：因为有单位元和逆元，所以ab =$a(b^{-1})^{-1} \in H$

定理三：判定定理：G是群，H是G的非空==有限==子集合，K是G的子群当且仅当：
$\forall a,b \in H,ab \in H$ 即只需满足封闭性，因为有限 ，其他性质根据封闭性自然成立
证明：
引理：非空有限群的元素的阶都是有限的
所以有单位元：$在序列 a，a^1 ,a^2 ……中，必有a^i = a^j ,则 e = a^{j-i}$ 所以存在单位元
也就有逆元：$a^{-1} = a^{j-i-1}$ 

平凡子群：全集群和单位元群


非平凡子群：
1.生成子群：$G是群，a \in G, a ≠ e ， H = \{a^{k}|k是整数\},记作 <a>$  
阶的关系：$|<a>| = |a|$，且是 |G| 的因子（因为元素的阶数一定是群的阶数的因子，否则做群的阶数次运算后无法得到单位元，与定义矛盾）
如果G存在一个元素的阶在1到 |G| 的开区间内部，则必然存在非平凡子群

H是G的一个子群，a是G中任一元素, aH = { ah | h ∈ H }，aH是G的子集，但是只有a∈H时，aH才是子群
