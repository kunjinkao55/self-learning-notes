#布尔代数定义
$$
\begin{aligned}
集合B满足有运算 \land 、 \lor 、 \neg 最大元1最小元0，\\满足结合律、交换律、分配律、同一律、补律，\\则称这个玩意是布尔代数
\end{aligned}
$$

唯一表示形式：A的幂集构成布尔代数（ρ(A)，∪，∩，~，空集，A）

#布尔代数性质
1~5 ：定义中的性质
6.双重补律：两次取非等于本身![[Pasted image 20250506104404.png]]

7.吸收律： $x \land (x \lor y) = (0 \lor x) \land (x \lor y) = x \lor (0 \land y)= x$

8幂等律 $x \land x = x \land(x \lor 0) = x$  (同一律，吸收律) 
也可以嵌套使用两次吸收律

9.支配律 1 + x = 1, 0 * x = 0

10.德摩根律

证明方法总结：待证明性质划归到其他已证明性质上

#有限布尔代数表示定理：
Intro：格中的原子（定义在格上，注意：格的范围比布尔代数更大）
	def：$0 \in L,\forall x \in L,有：0<x<=a \rightarrow x=a,称a是L中的原子$
		即：原子是仅比0大的元
		性质：原子之间不可比，原子a $\land$ 原子b = 0

定理内容：任一有限布尔代数B 同构于 B中所有的原子构成的集合A的幂集代数系统P(A)。 

集合A收集了布尔代数B

#布尔代数表示定理推论：
1.任何有限布尔代数的基数为$2^n$,n是自然数 （幂集的大小是这样的形式
设B是有限代数系统，A是B中所有原子的集合。
则：B 同构于 P(A),  |B|=|P(A)|=2^|A|

2.等势的有限布尔代数均同构
