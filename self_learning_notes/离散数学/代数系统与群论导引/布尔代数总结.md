### 1. 布尔代数的定义

**布尔代数 (Boolean Algebra)** 是一个代数系统，它由一个集合 B、两个二元运算（∧ 和 ∨）、一个一元运算（⋅）以及两个特殊的元素（0 和 1）构成。

- **集合：** B  
    
- **二元运算：**
    
    - ∧ （“与”，逻辑乘，交运算）
        
    - ∨ （“或”，逻辑加，并运算）
        
- **一元运算：**
    
    - ⋅ （“非”，补运算）
        
- **特殊元素：**
    
    - 0 （零元，最小元，逻辑假）
        
    - 1 （全一元，最大元，逻辑真），且 0=1  
        

这些构成需满足以下公理：

#### a. 基本公理：

对于任意 x,y,z∈B：

1. **结合律 (Associative Laws)：**
    
    - (x∨y)∨z=x∨(y∨z)  
        
    - (x∧y)∧z=x∧(y∧z)  
        
2. **交换律 (Commutative Laws)：**
    
    - x∨y=y∨x  
        
    - x∧y=y∧x  
        
3. **分配律 (Distributive Laws)：**
    
    - x∨(y∧z)=(x∨y)∧(x∨z) （∨ 对 ∧ 的分配律）
        
    - x∧(y∨z)=(x∧y)∨(x∧z) （∧ 对 ∨ 的分配律）
        
4. **同一律 (Identity Laws) / 有界性 (Boundedness)：**
    
    - x∨0=x  
        
    - x∧1=x  
        
5. **补律 (Complement Laws) / 有补格 (Complemented Lattice)：**
    
    - 对于任意 x∈B，存在一个元素 x∈B（称为 x 的补元），使得：
        
        - x∨x=1  
            
        - x∧x=0  
            

_(注：笔记中提到布尔代数的层级关系：代数格（满足结合律、交换律、吸收律、幂等律）_ → _分配格_ → _有界格（满足同一律、支配律）_ → _有补格（满足补律、双重补律、德摩根律）。实际上，吸收律和幂等律可以由其他公理推导出来，通常布尔代数的定义直接包含上述五条公理。)_

#### b. 典型实例：幂集代数

对于任意非空集合 A，其幂集 P(A)（或 P(A)）与集合的并、交、补运算构成一个布尔代数：

- 集合 B=P(A) （A 的所有子集构成的集合）
    
- 运算：
    
    - ∪ （集合并）对应 ∨  
        
    - ∩ （集合交）对应 ∧  
        
    - ∼ （集合的补集，相对于全集 A）对应 ⋅  
        
- 特殊元素：
    
    - ∅ （空集）对应 0  
        
    - A （全集）对应 1  
        

这通常被称为布尔代数的标准模型或原型。

### 2. 布尔代数的性质

除了定义中的公理外，布尔代数还具有以下重要性质，这些性质都可以由公理推导出来。

#### a. 定义公理（基本性质，为完整性重述）：

- 结合律
    
- 交换律
    
- 分配律
    
- 同一律
    
- 补律
    

#### b. 派生性质：

6. **双重补律 (Double Complementation Law)：** x=x  
    
    - **证明思路：** 利用补元的唯一性。要证明 x=x，只需证明 x 是 x 的补元，即满足：
        
        1. x∨x=1  
            
        2. x∧x=0
            
            这两条由补律和交换律直接可得。
            
    - **笔记中的证明方法（利用引理）：**
        
        - **引理：** ∀x,y,z∈B，若 x∧z=y∧z 且 x∨z=y∨z，则 x=y。
            
            - 引理证明：
                
                x=x∨(x∧z) （吸收律，见下文，或作为格的定义）
                
                x=x∨(y∧z) （由条件 x∧z=y∧z）
                
                x=(x∨y)∧(x∨z) （∨ 对 ∧ 的分配律）
                
                同理可得：
                
                y=y∨(y∧z) （吸收律）
                
                y=y∨(x∧z) （由条件 y∧z=x∧z）
                
                y=(y∨x)∧(y∨z) （∨ 对 ∧ 的分配律）
                
                因为 x∨z=y∨z 且 x∨y=y∨x（交换律），所以上述两式的右边相等，故 x=y。
                
        - 双重补律证明（应用引理）：
            
            令 y=x，z=x。
            
            1. 根据补律：x∨x=1。
                
            2. 根据补律（对 x 取补）：x∨x=1。
                
            3. 因此，x∨x=x∨x。
                
            4. 根据补律：x∧x=0。
                
            5. 根据补律（对 x 取补）：x∧x=0。
                
            6. 因此，x∧x=x∧x。
                
                根据引理，由于 x 和 x 分别与 x 进行 ∨ 和 ∧ 运算的结果都相同，所以 x=x。
                
7. **吸收律 (Absorption Laws)：**
    
    - x∧(x∨y)=x  
        
    - x∨(x∧y)=x  
        
    - 证明 x∧(x∨y)=x：
        
        x∧(x∨y)
        
        =(x∨0)∧(x∨y) （同一律：x=x∨0）
        
        =x∨(0∧y) （∨ 对 ∧ 的分配律）
        
        =x∨0 （支配律：0∧y=0，见下文）
        
        =x （同一律：x∨0=x）
        
    - 证明 x∨(x∧y)=x（笔记中的方法）：
        
        x∨(x∧y)
        
        =(x∧1)∨(x∧y) （同一律：x=x∧1）
        
        =x∧(1∨y) （∧ 对 ∨ 的分配律）
        
        =x∧1 （支配律：1∨y=1，见下文）
        
        =x （同一律：x∧1=x）
        
        (注：吸收律是格的定义的一部分。如果从格的定义出发，则无需证明。如果从布尔代数的五条公理出发，则可以如上推导。)
        
8. **幂等律 (Idempotent Laws)：**
    
    - x∧x=x  
        
    - x∨x=x  
        
    - 证明 x∧x=x（笔记中的方法）：
        
        x∧x=x∧(x∨0) （同一律：x=x∨0）
        
        =x （利用吸收律 A∧(A∨B)=A，令 A=x,B=0）
        
    - 另一种证明 x∧x=x：
        
        x=x∧1 （同一律）
        
        x=x∧(x∨x) （补律）
        
        x=(x∧x)∨(x∧x) （∧ 对 ∨ 的分配律）
        
        x=(x∧x)∨0 （补律）
        
        x=x∧x （同一律）
        
    - _证明_ x∨x=x _的方法与_ x∧x=x _对偶。_
        
9. **支配律 (Dominance Laws) / 有界律 (Bound Laws)：**
    
    - x∨1=1  
        
    - x∧0=0  
        
    - 证明 x∨1=1：
        
        x∨1=(x∨1)∧1 （同一律）
        
        =(x∨1)∧(x∨x) （补律）
        
        =x∨(1∧x) （∨ 对 ∧ 的分配律）
        
        =x∨x （同一律：1∧x=x）
        
        =1 （补律）
        
    - _证明_ x∧0=0 _的方法与_ x∨1=1 _对偶。_
        
10. **德摩根律 (De Morgan's Laws)：**
    
    - (x∧y)​=x∨y​  
        
    - (x∨y)​=x∧y​  
        
    - 证明 (x∧y)​=x∨y​（利用补元的唯一性）：
        
        要证明 x∨y​ 是 x∧y 的补元，需要验证以下两条：
        
        (i) (x∧y)∨(x∨y​)=1
        
        (ii) (x∧y)∧(x∨y​)=0
        
        证明 (ii)：
        
        (x∧y)∧(x∨y​)
        
        =((x∧y)∧x)∨((x∧y)∧y​) （分配律）
        
        =(x∧x∧y)∨(x∧y∧y​) （结合律和交换律）
        
        =(0∧y)∨(x∧0) （补律）
        
        =0∨0 （支配律）
        
        =0
        
        证明 (i)：
        
        (x∧y)∨(x∨y​)
        
        =((x∧y)∨x)∨y​ （结合律）
        
        =((x∨x)∧(y∨x))∨y​ （分配律，这里是 ∨ 对 ∧ 的分配律，但需要注意分配的对象）
        
        更清晰的步骤：
        
        (x∧y)∨x∨y​
        
        =(x∨x∨y​)∧(y∨x∨y​) （分配律 (A∧B)∨C=(A∨C)∧(B∨C) 的形式）
        
        我们使用更直接的分配方式：
        
        (x∧y)∨x∨y​
        
        =(x∨x∨y​)∧(y∨x∨y​) 这一步的分配律应用不直接，我们换一种方式。
        
        标准的证明 (i)：
        
        (x∧y)∨(x∨y​)
        
        =(x∨x∨y​)∧(y∨x∨y​) 这个分配律 (A∧B)∨C=(A∨C)∧(B∨C) 是错误的。
        
        正确的分配律是 C∨(A∧B)=(C∨A)∧(C∨B)
        
        我们重新证明 (i)：
        
        (x∧y)∨(x∨y​)
        
        =((x∧y)∨x)∨y​ (结合律)
        
        =(x∨(x∧y))∨y​ (交换律)
        
        =((x∨x)∧(x∨y))∨y​ (分配律)
        
        =(1∧(x∨y))∨y​ (补律)
        
        =(x∨y)∨y​ (同一律)
        
        =x∨(y∨y​) (结合律)
        
        =x∨1 (补律)
        
        =1 (支配律)
        
        由于 (x∨y​) 同时满足作为 (x∧y) 补元的两个条件，且在布尔代数中补元是唯一的，所以 (x∧y)​=x∨y​。
        
        (x∨y)​=x∧y​ 的证明与此对偶。

### 3. 有限布尔代数表示定理

#### a. 格与布尔代数中的原子 (Atom)

- **定义：** 在一个有最小元 0 的格 L 中，如果元素 a∈L 满足 a=0，并且对于任意 x∈L，若 0<x≤a，则必有 x=a，那么称 a 是格 L 中的一个原子。
    
    - 简而言之，原子是“直接覆盖” 0 的元素，即除了 0 之外不能再被其他元素严格小于自身的元素。
        
- **性质（在布尔代数中）：**
    
    - 任意两个不同的原子 a,b 是不可比的（除非 a=b）。
        
    - 若 a,b 是不同的原子，则 a∧b=0。
        
        - _证明：_ 因为 a∧b≤a 且 a∧b≤b。由于 a 是原子，若 a∧b=0，则 a∧b=a。同理，若 a∧b=0，则 a∧b=b。因此 a=b。所以如果 a=b，则必有 a∧b=0。
            

#### b. 定理内容 (Stone's Representation Theorem for Finite Boolean Algebras)

任何有限布尔代数 B 都同构于其所有原子构成的集合 A 的幂集代数 P(A)。

- 设 A=a1​,a2​,…,an​ 是布尔代数 B 中所有原子的集合。
    
- 则布尔代数 (B,∧B​,∨B​,⋅B​,0B​,1B​) 同构于幂集代数 (P(A),∩,∪,∼,∅,A)。
    
- **同构映射** f:B→P(A) **定义为：** 对于任意 x∈B，f(x)=a∈A∣a≤x。
    
    - 即 x 映射为其下方所有原子的集合。
        
- 重要结论： 在有限布尔代数中，任何非 0 元素都可以唯一地表示为其下方所有原子的并（∨ 运算）。
    
    x=⋁a∣a∈A,a≤x
    

#### c. 推论

1. **任何有限布尔代数的基数（元素个数）都是** 2n **的形式**，其中 n 是该布尔代数中原子的个数。
    
    - 因为 B 同构于 P(A)，所以 ∣B∣=∣P(A)∣。如果原子集合 A 的大小为 ∣A∣=n，则其幂集 P(A) 的大小为 2∣A∣=2n。
        
2. **任何两个等势（具有相同元素个数）的有限布尔代数都是同构的。**
    
    - 如果两个有限布尔代数 B1​,B2​ 都有 2n 个元素，则它们都分别同构于 n 个原子集合的幂集代数，因此它们彼此同构。
        

### 4. 因子格 Dn​ 是否构成布尔代数

Dn​ 是正整数 n 的所有正因子构成的集合，其上的偏序关系为“整除”关系（a≤b 当且仅当 a∣b）。

运算定义为：

- a∧b=gcd(a,b) （最大公约数）
    
- a∨b=lcm(a,b) （最小公倍数）
    
- 0 对应因子 1  
    
- 1 对应因子 n  
    

#### a. Dn​ 构成布尔代数的条件

如果 n 是 **无平方因子** 的正整数（即 n 可以表示为不同素数的乘积，n=p1​p2​…pk​，其中 pi​ 均为不同的素数），那么 Dn​ 是一个布尔代数。

- **解释：**
    
    - 令 S=p1​,p2​,…,pk​ 为 n 的所有不同素因子集合。
        
    - Dn​ 中的每个因子 d 对应 S 的一个子集 T⊆S，使得 d=∏p∈T​p。
        
    - 这种对应关系建立了一个从 P(S) 到 Dn​ 的同构：f:P(S)→Dn​，定义为 f(T)=∏p∈T​p。
        
    - 空集 ∅ 对应因子 1（约定空积为 1）。
        
    - 全集 S 对应因子 n。
        
    - 对于 T1​,T2​⊆S：
        
        - f(T1​∩T2​)=gcd(f(T1​),f(T2​))  
            
        - f(T1​∪T2​)=lcm(f(T1​),f(T2​))  
            
        - f(S∖T)=n/f(T) （补元）
            
    - 由于 P(S) 是一个布尔代数，且 Dn​ 与其同构，所以 Dn​ 也是一个布尔代数。
        
    - 此时，Dn​ 中的原子是 n 的各个素因子 p1​,p2​,…,pk​。
        

#### b. Dn​ 不构成布尔代数的条件

如果 n **含有平方因子**（即存在某个素数 p 使得 p2∣n），那么 Dn​ **不是** 一个布尔代数。

- **证明（根据笔记，通过补律冲突）：**
    
    - 假设 Dn​ 是一个布尔代数。
        
    - 因为 p2∣n，所以 n=p2q 对于某个正整数 q 成立。
        
    - 元素 p 是 Dn​ 中的一个因子（因为 p∣p2q=n）。
        
    - 如果 Dn​ 是布尔代数，那么 p 必须有一个补元 p′，满足：
        
        1. gcd(p,p′)=1 （即 p∧p′=0B​）
            
        2. lcm(p,p′)=n （即 p∨p′=1B​）
            
    - 从 lcm(p,p′)=n 和 gcd(p,p′)⋅lcm(p,p′)=p⋅p′ 的性质，我们有 1⋅n=p⋅p′，所以 p′=n/p。
        
    - 将 n=p2q 代入，得到 p′=(p2q)/p=pq。
        
    - 现在我们检查条件 gcd(p,p′)=1：
        
        gcd(p,pq)=p。
        
    - 要使 gcd(p,pq)=1（Dn​ 中的 0 元），则必须 p=1，但这与 p 是素数矛盾。
        
    - 因此，条件 gcd(p,p′)=1 不成立（除非 p=1，但素数 p≥2）。
        
    - 这意味着元素 p 在 Dn​ 中没有补元。
        
    - 所以，如果 n 含有平方因子，Dn​ 不是一个布尔代数。
        
    - 更准确的解释：
        
        gcd(p,p′)=1 (这里的 1 是 Dn​ 中的最小元，即整数 1)
        
        lcm(p,p′)=n
        
        由 p′=n/p=(p2q)/p=pq。
        
        则 gcd(p,p′)=gcd(p,pq)=p。
        
        要使 gcd(p,pq)=1，则 p 必须等于 1。但 p 是一个素数，所以 p≥2。
        
        因此 gcd(p,pq)=p=1。
        
        这意味着 p 的“候选补元” pq 并不满足 p∧p′=1 (0B​) 的条件。所以 p 在这种情况下没有补元。
        

### 5. 应用简介

笔记最后提到了布尔代数的一个应用：

- **电路化简：** 布尔代数是数字逻辑电路设计和简化的理论基础。逻辑门（与门、或门、非门等）的行为可以用布尔运算来描述，布尔代数的各种定律（如分配律、吸收律、德摩根律等）可以用来化简逻辑表达式，从而减少电路中所需逻辑门的数量和复杂性。
