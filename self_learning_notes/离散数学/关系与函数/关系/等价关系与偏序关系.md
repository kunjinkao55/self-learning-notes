一、等价关系与等价类
def：等价关系满足： 自反性 对称性 传递性
def 等价类：
	R是非空集合A上的等价关系，与A中一个元素a有关系R的所有元素的集合叫做a的等价类，记作$[a]_R$ ，a称作代表元

商集：所有等价类构成的集合

集合的划分 $\equiv$ 商集 
商集的个数：贝尔数
计算公式：$B_{n+1} = \sum_{k = 0}^n{C(n,n-k) * B_{k}}$
说明：插入一个新元素时，挑选n-k个元素和他组成一个划分，这个组合数再乘剩下的元素划分数
k遍历所有可能取值
注：组合数C（n，k） = C（n，n-k）

应用：利用等价类构造鸽笼原理，但是鸽笼数和贝尔数没啥关系，因为鸽笼针对的是某种特殊构造的划分

二、偏序关系 
def ： 自反性 反对称性 传递性 
记号： ≤
特殊：由反对称性定义 ，（ 恒等于 $\equiv$ ） 也是偏序关系

def 可比性：(a,b) ∈ R 或者 （b,a) ∈ R， R 为偏序关系

def 全序关系（线序关系）： R 是 A 上的偏序关系 ， 任取x，y ∈ A ，x和y都是可比的

def 覆盖： x < y 且 不存在 z 使得 x < z < y，则称 y 覆盖 x


三、偏序集和哈斯图
def 偏序集：集合A 和 A上的偏序关系≤ 一起叫做偏序集 记作 （A，≤）
