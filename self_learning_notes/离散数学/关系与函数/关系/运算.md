1.定义域运算： dom R ={ $x| \exists y (x,y) \in R$}
2.值域运算： ran R ={ $y| \exists x (x,y) \in R$}
3.fld R = dom R ∪ ran R
### 4\. **$R↑A$（或 $R \uparrow A$）**

- 这个表示**对关系 $R$ 进行限制（restriction）**，即只保留 **$R$ 中第一个元素（即左侧元素）属于 $A$ 的元组**。
- 形式化定义：
	$$
	R↑A = \{ (x, y) \mid x \in A \land (x, y) \in R \}
	$$
- 也可以写作 $R \restriction A$ 或 $R | A$。

### 5\. **$R[A]$**

- 这个表示关系 $R$ **在第一个元素属于 $A$ 的情况下，收集所有的第二个元素的集合**。
- 形式化定义：
	$$
	R[A] = \{ y \mid \exists x \in A, (x, y) \in R \}
	$$
- 也就是 $R↑A$ 中所有第二个元素的集合。

### 1\. 0-1矩阵运算

- **定义：** 这里的矩阵 $M1M_1M1$ 和 $M2M_2M2$ 都是由 0 和 1 组成的矩阵，形式为：
	$$
	M1=[aij],M2=[bij]M_1 = [a_{ij}], M_2 = [b_{ij}]M1=[aij],M2=[bij]
	$$
	其中 $aija_{ij}aij$ 和 $bijb_{ij}bij$ 为矩阵 $M1M_1M1$ 和 $M2M_2M2$ 中的元素，值为 0 或 1。

### 2\. 逻辑与（AND）运算

- **定义：** 对于两个矩阵 $M1M_1M1$ 和 $M2M_2M2$ ，我们可以进行 **逻辑与运算（AND）** ，得到一个新矩阵 $CCC$ ，其元素 $cijc_{ij}cij$ 满足：
	$$
	cij=1 仅当 aij=1 且 bij=1c_{ij} = 1 \text{ 仅当 } a_{ij} = 1 \text{ 且 } b_{ij} = 1cij=1 仅当 aij=1 且 bij=1
	$$
	这表示只有当 $M1M_1M1$ 和 $M2M_2M2$ 对应位置的元素都为 1 时，结果矩阵 $CCC$ 中该位置的元素才为 1。

### 3\. 逻辑或（OR）运算

- **定义：** 对于矩阵 $M1M_1M1$ 和 $M2M_2M2$ ，我们也可以进行 **逻辑或运算（OR）** ，得到一个新矩阵 $CCC$ ，其元素 $cijc_{ij}cij$ 满足：
	$$
	cij=1 当且仅当 aij=1 或 bij=1c_{ij} = 1 \text{ 当且仅当 } a_{ij} = 1 \text{ 或 } b_{ij} = 1cij=1 当且仅当 aij=1 或 bij=1
	$$
	这表示只要 $M1M_1M1$ 或 $M2M_2M2$ 对应位置的元素为 1，则结果矩阵 $CCC$ 中该位置的元素为 1。

### 4\. 0-1矩阵的复合运算

- 对于两个矩阵 $M1M_1M1$ 和 $M2M_2M2$ ，我们可以进行 **矩阵的复合运算（也叫做矩阵乘积运算）** ，表示为 $M1⊗M2M_1 \otimes M_2M1⊗M2$ 。该运算可以理解为类似矩阵乘法的过程，具体定义如下：
	$$
	cij=1 当且仅当 存在 k ，使得 aik=1 且 bkj=1c_{ij} = 1 \text{ 当且仅当 存在 k ，使得 } a_{ik} = 1 \text{ 且 } b_{kj} = 1cij=1 当且仅当 存在 k ，使得 aik=1 且 bkj=1
	$$
	这意味着矩阵 $M1M_1M1$ 的第 $iii$ 行和矩阵 $M2M_2M2$ 的第 $kkk$ 行满足逻辑与的关系，且矩阵 $M2M_2M2$ 的第 $kkk$ 列和第 $jjj$ 列满足逻辑与。

#闭包的定义（性质）
称R是集合A上的关系：对给定性质P
R1满足性质P
R 包含于 R1
如果存在集合上的关系R2，R2 满足性质P 且 R 包含于 R2，则有 R1 包含于 R2 （即：R1是最小的）
则称 R1 是关系R 的闭包

计算公式：
自反闭包：$r(R) = R \lor I_A，I_A是集合A上的恒等关系$
对称闭包：$s(R) = R \lor R^{-1}$
关键点是证明闭包是最小的

传递闭包：连通关系 t(R)

人话：关系矩阵逐行逐列扫描：第i行所有为1的列与第二列所有为1的行的交点更新为1，i从1到n遍历矩阵

def warshall_verbose(adj_matrix):
    """
    Warshall 算法，带迭代可视化：计算传递闭包，同时打印每一轮中间结果
    """
    n = len(adj_matrix)
    closure = [row[:] for row in adj_matrix]

    print_matrix(closure, "初始矩阵")

    for k in range(n):
        print(f"\n—— 迭代 k = {k} ——")
        for i in range(n):
            for j in range(n):
                if closure[i][k] and closure[k][j]:
                    if not closure[i][j]:
                        print(f"设置 closure[{i}][{j}] = 1（因为 closure[{i}][{k}] = 1 且 closure[{k}][{j}] = 1）")
                    closure[i][j] = 1
        print_matrix(closure, f"k = {k} 后的传递闭包")

    return closure

def print_matrix(matrix, title=None):
    if title:
        print(f"\n{title}")
    for row in matrix:
        print(" ".join(str(x) for x in row))

    closure = warshall_verbose(adj_matrix)
    print_matrix(closure, "最终传递闭包")
